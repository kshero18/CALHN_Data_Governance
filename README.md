# CALHN Data Governance Dashboard

## Project Overview
This project demonstrates a healthcare data governance workflow using patient feedback and complaints data. The aim is to assess data quality, identify operational issues, and present insights through a Power BI dashboard.

## Objectives
- Clean and standardise complaints/feedback data
- Identify missing, invalid, and inconsistent records
- Create data-quality summary reports
- Build a Power BI dashboard for stakeholder decision-making

## Data Quality Checks
- Missing value analysis
- Invalid date format detection
- Future date detection
- Negative resolution time detection
- Out-of-range satisfaction score detection
- Duplicate identifier checks

## Tools Used
- Power BI
- CSV data processing
- Data quality profiling
- Custom Power BI theme

## Dashboard Insights
The dashboard highlights feedback themes, service areas, complaint status, satisfaction scores, and data-quality issues that may affect reporting accuracy.

## Privacy Note
This project uses simulated or de-identified healthcare feedback data for portfolio and learning purposes.
